### Why this repo exists

The user asked for "a similar backend" to
[mwanachama-backend-taskmanager](../../../mwanachama-backend-taskmanager) for
general asset/inventory tracking — warehouses, supermarkets, household
inventories, livestock — reusing the same `entitygraph.DataManager`
architecture. Confirmed mid-session it should eventually be able to back
the Mwanachama party's existing merchandise domain too, which shaped the
ledger-first, hold-capable design in `1. requirements/requirements.md`
without coupling this repo to that domain's tier/RLS model.
